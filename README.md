# 🐍 Snake Game

A classic Snake Game developed using **HTML, CSS, and JavaScript**. Guide the snake using the arrow keys, collect food to earn points, and try to achieve your highest score while avoiding collisions with the walls and your own body.

## 🎮 Features

- **Classic Gameplay** — Control the snake using keyboard arrow keys.
- **Score Tracking** — Earn 10 points each time the snake eats food.
- **High Score** — Save and maintain your best score using browser Local Storage.
- **Game Timer** — Keep track of your playing time.
- **Collision Detection** — Detect collisions with walls and the snake's own body.
- **Restart Option** — Restart the game after a game-over event.
- **Game Status Display** — View the current score, high score, timer, and game status.
- **Dynamic Game Board** — Arrange the game area using CSS Grid.

## 🛠️ Technologies Used

- **HTML5** — Provides the structure of the game.
- **CSS3** — Handles the layout, colors, and visual styling.
- **JavaScript** — Manages snake movement, scoring, timing, and collision detection.
- **Browser Local Storage** — Stores the highest score between visits in the same browser.

## 🚀 Getting Started

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/mg2658094-hub/Snake-Game.git
```

### 2. Navigate to the Project Folder

```bash
cd Snake-Game
```

### 3. Run the Game

Open `index.html` in your web browser, or open the project folder in Visual Studio Code and run it using the Live Server extension.

**Note:** This project uses plain HTML, CSS, and JavaScript. No additional packages or build tools are required.

## 🕹️ How to Play

1. Open the game in your browser.
2. Click **Start Game** to begin.
3. Use the arrow keys to change the snake's direction.
4. Collect the red food to increase your score.
5. Avoid hitting the walls or the snake's own body.
6. Try to beat your previous high score.
7. Click **Restart Game** after a game-over event to start another round.

### ⌨️ Keyboard Controls

| Key | Action |
|---|---|
| ⬆️ Arrow Up | Move up |
| ⬇️ Arrow Down | Move down |
| ⬅️ Arrow Left | Move left |
| ➡️ Arrow Right | Move right |

## 📊 Scoring System

- Each food item adds **10 points** to the current score.
- The current score resets when a new game starts.
- The highest score is saved in browser Local Storage.
